# Multi-Asset Market Risk Engine v0.1.0

Initial public portfolio release.

## Highlights

- Three VaR/ES approaches across configurable confidence levels.
- Leak-free next-interval forecasts and statistical exception tests.
- ETF, duration-convexity bond, cash, and direct FX-overlay accounting.
- Additive position, asset-class, and factor risk contributions.
- Six hypothetical scenarios, distributional stress, and crisis-replay fixtures.
- Eight figures, automated Markdown reporting, Colab notebook, CLI, and 22 tests.

## Evidence Boundary

The bundled snapshot is deterministic and synthetic so the complete project is reproducible without credentials. Numerical outputs demonstrate implementation behaviour and must not be described as historical market findings. Optional live adapters are provided for a separately governed real-data run.
